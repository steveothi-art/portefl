# 💻 MAEWEN'S PORTFOLIO

## 📌 Présentation du projet

**Maewen's Portfolio** est un site web personnel conçu pour présenter mon identité professionnelle, mes compétences techniques, mes réalisations et mon évolution dans le domaine de l'informatique.

Ce portfolio représente également l'univers de **Maewens**, une initiative personnelle orientée vers la conception de solutions numériques, le développement web et les infrastructures réseau.

L'objectif est de disposer d'une vitrine professionnelle moderne, interactive et accessible sur différents appareils.

## 🎯 Objectifs

- Présenter mon profil et mon parcours professionnel.
- Mettre en valeur mes compétences en développement web et en réseau informatique.
- Exposer mes projets réalisés et mes travaux pratiques.
- Permettre aux visiteurs de consulter et télécharger mon CV.
- Faciliter la prise de contact pour des collaborations, stages et projets informatiques.
- Développer progressivement l'identité numérique de Maewens.

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|---|---|
| HTML5 | Structure et organisation des pages |
| CSS3 | Mise en forme, responsive design et animations |
| JavaScript | Interactions et fonctionnalités dynamiques |
| SVG | Représentation graphique de l'architecture réseau |
| Git | Gestion des versions |
| GitHub | Hébergement et partage du code source |

Le projet repose sur une architecture front-end classique, sans framework obligatoire.

## 🚀 Installation et utilisation

### Étape 1 : Récupérer le projet

Cloner le dépôt GitHub :

```bash
git clone https://github.com/VOTRE-UTILISATEUR/maewens-portfolio.git
```

Remplacer `VOTRE-UTILISATEUR` par le nom du compte GitHub hébergeant le projet.

### Étape 2 : Ouvrir le dossier

```bash
cd maewens-portfolio
```

### Étape 3 : Lancer le portfolio

Ouvrir le fichier `index.html` dans un navigateur web.

Il est également possible d'utiliser l'extension **Live Server** dans Visual Studio Code.

Aucune installation de dépendances Node.js n'est nécessaire pour la version HTML/CSS/JavaScript.

## ⚙️ Personnalisation

Pour adapter le portfolio :

1. Modifier les informations personnelles dans `index.html`.
2. Ajuster les couleurs et animations dans `style.css`.
3. Adapter les interactions dans `script.js`.
4. Remplacer les images par les ressources souhaitées.
5. Ajouter de nouveaux projets dans la section `#projets`.
6. Renseigner les liens fonctionnels des projets et de WhatsApp.
7. Remplacer le document PDF actuel par un véritable CV.

## 📱 Compatibilité

Le portfolio est conçu pour s'adapter aux principaux formats d'écran :

- Ordinateurs de bureau.
- Ordinateurs portables.
- Tablettes.
- Smartphones.

La compatibilité effective dépend des styles CSS et des fonctionnalités JavaScript implémentés.
